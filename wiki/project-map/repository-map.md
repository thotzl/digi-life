# Repository Map

Module-level map of the code. Layout since TCK-124: `Cargo.toml`, `tauri.conf.json` and `package.json` at the root, `src/` = Rust, `frontend/` = UI, no `src-tauri/`. Deliberately no functions or line numbers — read the code for details. Update only when a module is added, removed or changes responsibility.

## Root

| Path | Responsibility |
| :--- | :--- |
| `Cargo.toml`, `build.rs` | Rust crate (Tauri app + `trainer_runner` binary) |
| `rustfmt.toml`, `eslint.config.js` | Rust formatting (`max_width = 120`) and frontend ESLint config, both checked in CI (TCK-161, [[wiki/quality/ci-and-tooling]]) |
| `package.json`, `vite.config.ts`, `tsconfig.json`, `vitest.config.ts` | frontend build and tests |
| `tauri.conf.json`, `capabilities/`, `icons/`, `gen/` | Tauri config, permissions, bundle icons, generated schemas |
| `tauri.dev.conf.json` | dev-app override merged by `npm run tauri:dev`: own identifier (`.dev`) and window title (TCK-195) |
| `scripts/` | release packaging: `package-portable.mjs` (portable Windows ZIP) and `portable/LIESMICH.txt` ([[wiki/quality/ci-and-tooling]], TCK-195) |
| `config.json` | simulation parameters, embedded into the binary ([[wiki/architecture/configuration]]) |
| `index.html` | single mount point |
| `bindings/` | ts-rs output, generated by `cargo test`, committed ([[wiki/architecture/ipc-protocol]]) |

| `.agents/` | agent skills and state |
| `wiki/` | this wiki |
| `CHANGELOG.md` | release notes = list of finished work |
| `ideas.md` | research dossier ([[wiki/research/_index]]) |

## Key Takeaways

- Rust: `server/` = runtime and API, `biology/` = genome, creature factory, metabolism, trainer config and store, `trainer/` = trainer, `diagnostics/` = runner report and probes, `shared/` = brain, physics, world, types, RNG, math; `bin/` = headless runner.
- Frontend: router + two loop modules + views + renderers.
- Every module row links to the article that explains it.
