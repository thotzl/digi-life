# Repository Map

Module-level map of the code. Deliberately no functions or line numbers — read the code for details. Update only when a module is added, removed or changes responsibility.

## Root

| Path | Responsibility |
| :--- | :--- |
| `Cargo.toml`, `build.rs` | Rust crate (Tauri app + `cli_trainer` binary) |
| `package.json`, `vite.config.ts`, `tsconfig.json`, `vitest.config.ts` | frontend build and tests |
| `tauri.conf.json`, `capabilities/`, `icons/`, `gen/` | Tauri config, permissions, bundle icons, generated schemas |
| `config.json` | simulation parameters, embedded into the binary ([[architecture/configuration]]) |
| `index.html` | single mount point |
| `bindings/` | ts-rs output, generated by `cargo test`, committed ([[architecture/ipc-protocol]]) |
| `.github/workflows/` | CI, releases, ticket sync ([[quality/ci-and-tooling]]) |
| `.tickets/` | tickets (open/ongoing/closed) |
| `.agents/` | agent skills and state |
| `wiki/` | this wiki |
| `CHANGELOG.md` | release notes |
| `ideas.md` | research dossier ([[research/_index]]) |

## Key Takeaways

- Rust: `server/` = runtime and API, `biology/` = genome and trainer, `shared/` = brain, physics, world, types.
- Frontend: router + two loop modules + views + renderers.
- Every module row links to the article that explains it.
