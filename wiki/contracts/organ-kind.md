# Contract: organ kind

## Purpose

An organ kind is what an organ gene (`EYE`, `NOS`, `TAC`, `LUM`) becomes once its payload is decoded: the kind
decides how the organ senses, which input channels are wired, what it costs, whether it counts as a limb and how it
is named and shown. Kinds today: `Eye`, `Nose`, `Thermal` (spectral distance senses), `Bristle`, `LateralLine`,
`Proprioceptor` (tactile). Planned kinds (e.g. claws, electroreceptors) are added as one file each. Current behaviour:
[[wiki/biology/sensing]], [[wiki/biology/genome-compiler]].

## Signature

```rust
// src/biology/organs/mod.rs
pub enum OrganKind { Eye, Nose, Thermal, Bristle, LateralLine, Proprioceptor }
impl OrganKind {
    pub const ALL: [OrganKind; 6];
    pub fn spec(self) -> &'static OrganSpec;                         // the one dispatch point (exhaustive match)
    pub fn classify(spectral_affinity: f32, expression_style: f32) -> Self;
    pub fn is_distance(self) -> bool;                                // spec().distance
}
pub struct OrganSpec {
    pub kind: OrganKind,
    pub name: &'static str,                                          // display (frontend)
    pub channel_names: [&'static str; SPECTRAL_CHANNELS],            // display of channels 0..5
    pub distance: bool,                                              // spectral distance sense with ΔI
    pub live_channels: fn(&Organ) -> [bool; CHANNELS_PER_ORGANELLE], // channels that are wired
    pub sense: fn(&SenseCtx, &Organ, &mut [f32; CHANNELS_PER_ORGANELLE]),
    pub cost_load: fn(&Organ) -> f32,                                // metabolic organ load
    pub limb: bool,                                                  // kind can grow as a limb (never a distance sense)
    pub ballast: f32,                                                // drag units (× physics.receptorBallastScale)
    pub latin_suffix: &'static str,
    pub latin_rank: u8,                                              // tie-break of the dominant suffix
}
pub struct Organ { spectral_affinity, bandwidth, expression_style, scale, spinal_pos, angle, hue_shift,
                   gene_start_index, gene_end_index, kind: OrganKind, side: OrganSide }   // range(), power(), is_limb()
// Organ::is_limb() = spec().limb && expression_style >= LIMB_STYLE (0.72)
pub struct SenseCtx<'a> { agent: &CreatureAgent, foods: &[FoodSpore], obstacles: &[ProceduralObstacle], width, height }
```

Shared building blocks a kind points to: `spectral::{live_channels, sense}` (tuning curve over plant/meat emission),
`contact::{boundary_pressure, touch_pressure, water_temperature, pain}` (`water_temperature` reads the depth field
`shared::temperature::TemperatureField::WATER`, the field of the Ocean's thermal stress), `common::cost_load`.

## Lifecycle / call order

1. Compile (`parse_genome`, once per genome): `decode_organs` decodes every organ gene with the same loci and calls
   `classify`; `compile_brain` asks `live_channels` per organ gene and wires a thalamus node per live channel.
2. Every tick (Ocean, trainer, probes): `compute_sensory_inputs` builds one `SenseCtx` and calls `sense` per organ
   with a zeroed `[f32; 6]`; the host clamps each slot to [0, 1] and writes slot `organ_index · 6 + channel`. The
   brain step fills ΔI (channel 5) of distance senses from consecutive ticks.
3. Every tick: `metabolism::organ_load` sums `cost_load`; `physics` reads `Organ::is_limb` (speed band) and `ballast`
   (drag).
4. Display: `bindings/organRegistry.ts` (generated by `cargo test`) gives the frontend `name`, `channel_names` and
   `limb`; the renderer draws a fleshy limb exactly when `Organ::is_limb` holds (`frontend/render/organs.ts` `isLimb`).

## Invariants

- `sense` is pure: it reads `SenseCtx` and the organ, writes only `out`, draws no random numbers, uses
  `crate::shared::fmath` for trigonometry (determinism, epic principle 5).
- `live_channels` agrees with `sense`: a channel `sense` can make non-zero is live, and every live channel but ΔI
  carries a stimulus in some state (test `test_live_channels_match_sense`). A non-live channel is never wired.
- Food layout: `foods[0]` nearest plant, `foods[1]` nearest meat (scenarios and Ocean build it so).
- Only limb-capable kinds drive locomotion as limbs; distance senses (`Eye`, `Nose`, `Thermal`) have `limb: false`
  (TCK-202).
- Channels are clamped to [0, 1]; signed quantities keep one side by design: the lateral line registers flow arriving
  head-on at the organ's axis (backward-facing organs register the opposite flow), the proprioceptor one bend side
  (reviewed in TCK-202).
- A new kind or a changed spec of an existing kind is a model change: golden master, trainer references and
  `MODEL_VERSION` follow invariants 8 and 9 of [[wiki/architecture/invariants]]. Adding a kind that no genome can
  classify into yet changes nothing.

## Registration point

One variant in `OrganKind` (and `OrganKind::ALL`), one arm in `OrganKind::spec`, and the region of the (affinity,
style) square in `OrganKind::classify`. The compiler's exhaustive `match` in `spec` reports a missing arm.

## Config keys

None of its own today. `physics.receptorBallastScale` scales `ballast`; `metabolism.organCostPerLoad` scales
`cost_load` ([[wiki/contracts/config-section]]). A kind that needs a tunable adds a key to the section that reads it.

## Events / IPC

The phenotype's `organelles: Organ[]` and `NeuronRole::Sensor { kind }` reach the frontend in every creature payload
(bindings `Organ.ts`, `OrganKind.ts`); `bindings/organRegistry.ts` holds the display names. No actions.

## Test recipe

`cargo test organs::` runs `test_live_channels_match_sense` and `test_specs_belong_to_their_kind` over
`OrganKind::ALL` (a new kind is covered automatically) and regenerates `bindings/organRegistry.ts`. Then the full gate:
`cargo test` (golden master), the three trainer reference runs of `.github/workflows/ci.yml`, `npm test`,
`npm run build`.

## Minimal example

```rust
// src/biology/organs/electroreceptor.rs: senses the nearest meat spore by distance only (channel 4)
use super::{common, Organ, OrganKind, OrganSpec, SenseCtx, CHANNELS_PER_ORGANELLE};

fn live_channels(_: &Organ) -> [bool; CHANNELS_PER_ORGANELLE] {
    [false, false, false, false, true, false]
}

fn sense(ctx: &SenseCtx, organ: &Organ, out: &mut [f32; CHANNELS_PER_ORGANELLE]) {
    if let Some(meat) = ctx.foods.get(1) {
        let d = crate::shared::geom::dist(ctx.agent.px, ctx.agent.py, meat.x, meat.y);
        out[4] = (1.0 - d / organ.range()).max(0.0) * organ.power();
    }
}

pub const SPEC: OrganSpec = OrganSpec {
    kind: OrganKind::Electroreceptor,
    name: "Electroreceptor",
    channel_names: ["-", "-", "-", "-", "Field"],
    distance: false,
    live_channels,
    sense,
    cost_load: common::cost_load,
    limb: false,
    ballast: 1.0,
    latin_suffix: "electricum",
    latin_rank: 4,
};
```
