# Decisions (ADRs)

Architecture decision records. None recorded yet. Decisions made so far are documented as non-goals in [[roadmap]] and as design decisions in the pool tickets (TCK-143..161).

## Convention

- File: `decisions/adr-NNN-short-title.md`, numbered consecutively, never renumbered.
- A superseded ADR stays; its status points to the successor.

## Template

```markdown
# ADR-NNN: <title>

- Status: proposed | accepted | superseded by ADR-MMM
- Date: YYYY-MM-DD
- Tickets: TCK-…

## Context
## Decision
## Consequences
```
